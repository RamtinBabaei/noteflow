# اجرای پروژه در VS Code

پیش‌نیاز: Node.js نسخهٔ ۲۲٫۱۳ یا بالاتر؛ نسخهٔ ۲۴ پیشنهاد می‌شود.

۱. فایل ZIP را استخراج کنید و پوشهٔ `noteflow` را در VS Code باز کنید. پوشه‌ای را انتخاب کنید که فایل `package.json` داخل آن است.

۲. از منوی Terminal گزینهٔ New Terminal را بزنید. دستورها را به‌ترتیب اجرا کنید:

```powershell
corepack enable
pnpm install --frozen-lockfile
pnpm setup:local
pnpm dev
```

اگر دستور Corepack پیدا نشد، ابتدا `npm install -g pnpm@11.25.0` را اجرا کنید و از مرحلهٔ نصب وابستگی‌ها ادامه دهید.

۳. آدرس زیر را در مرورگر باز کنید:

http://localhost:5173

۴. برای بررسی عملکرد، یک یادداشت جدید بسازید، عنوان و متن بنویسید، Save Note را بزنید و صفحه را تازه‌سازی کنید. یادداشت باید باقی بماند. سپس جست‌وجو، تگ‌ها، آرشیو و بازیابی را امتحان کنید. رنگ و فونت از Settings تغییر می‌کنند.

۵. برای بررسی خودکار کدها، در یک ترمینال جدید اجرا کنید:

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

برای تست HTTP، سرور باید در ترمینال اول همچنان در حال اجرا باشد. در ترمینال دوم بنویسید:

```powershell
$env:TEST_BASE_URL = 'http://localhost:5173'
pnpm test:http
```

در پایان باید پیام عبور ۱۸ بررسی HTTP نمایش داده شود. برای توقف سرور، Ctrl+C را بزنید.

اطلاعات لوکال از نسخهٔ آنلاین جداست. برای اجرای محلی به کلید API، ورود به Cloudflare یا نصب PostgreSQL نیاز ندارید. این نسخه فضای مهمان دارد و اطلاعات آن به مرورگر وابسته است؛ برای تهیهٔ نسخهٔ پشتیبان از Export notes استفاده کنید.
